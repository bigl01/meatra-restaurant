# Установка плагинов WordPress для Meatra

## Какие плагины нужны

| Плагин | Зачем |
|--------|------|
| **Advanced Custom Fields (ACF)** | Кастомные поля (цена, вес, фото и т.д.) |
| **ACF to REST API** | Доступ к полям ACF через API |
| **Custom Post Type UI** | Типы записей: меню, события, команда, вакансии |

---

## Пошаговая установка

### Шаг 1: Войдите в админку WordPress

1. Откройте в браузере: **https://testdomen.store/wp-admin**
2. Введите логин и пароль
3. Вы окажетесь в панели управления

---

### Шаг 2: Откройте раздел плагинов

1. В левом меню найдите **«Плагины»** (Plugins)
2. Нажмите **«Добавить новый»** (Add New)

---

### Шаг 3: Установите Advanced Custom Fields

1. В поле поиска введите: **Advanced Custom Fields**
2. Найдите плагин **«Advanced Custom Fields»** от WP Engine
3. Нажмите **«Установить»** (Install Now)
4. После установки нажмите **«Активировать»** (Activate)

---

### Шаг 4: Установите ACF to REST API

1. Снова откройте **Плагины → Добавить новый**
2. В поиске введите: **ACF to REST API**
3. Найдите плагин **«ACF to REST API»** (автор: Aires Gonçalves)
4. Нажмите **«Установить»** → **«Активировать»**

---

### Шаг 5: Установите Custom Post Type UI

1. **Плагины → Добавить новый**
2. В поиске: **Custom Post Type UI**
3. Найдите плагин **«Custom Post Type UI»** (автор: WebDevStudios)
4. Нажмите **«Установить»** → **«Активировать»**

---

### Шаг 6: Проверка

В левом меню должны появиться новые пункты:

- **ACF** (или «Произвольные поля») — настройка полей
- **CPT UI** — настройка типов записей

---

## Что делать дальше

После установки плагинов нужно **создать типы записей** и **настроить поля ACF**.

Подробная инструкция — в файле **DEPLOYMENT.md** (разделы «Настройка Custom Post Types» и «Настройка ACF полей»).

Кратко:
1. **CPT UI → Add New** — создать типы: `main_menu`, `game_menu`, `events_details`, `team_members`, `vacancies`, `benefits`
2. **ACF** — создать группы полей для каждого типа (цена, вес, фото и т.д.)

---

## Если плагин не находится в поиске

Некоторые плагины могут быть платными или недоступны. Альтернативы:

- **ACF** — есть бесплатная версия, её достаточно
- **ACF to REST API** — бесплатный
- **Custom Post Type UI** — бесплатный

Если что-то не находится — напишите название плагина, подскажу альтернативу.
