# Какие группы полей ACF создавать

Создайте **6 групп полей** — по одной на каждый тип контента. В каждой группе укажите, к какому типу записей она относится, и включите **«Show in REST API»**.

---

## Порядок действий

1. Сначала создайте типы записей в **CPT UI** (main_menu, game_menu и т.д.)
2. Потом создайте группы полей в **ACF** и привяжите их к этим типам

---

## Группа 1: Основное меню и Меню из дичи

**Название группы:** Поля меню (Main Menu / Game Menu)

**Расположение:** Post Type = `main_menu` **И** `game_menu`  
(в настройках группы можно выбрать несколько типов)

| Имя поля (Name) | Метка (Label) | Тип | Обязательное |
|-----------------|---------------|-----|--------------|
| price | Цена | Text | Нет |
| weight | Вес | Text | Нет |
| ingredients | Ингредиенты | Textarea | Нет |
| category | Категория | Text | Нет |
| image | Изображение | Image | Нет |

**Внизу страницы:** включите **Show in REST API** → Сохранить

---

## Группа 2: События

**Название группы:** Поля события

**Расположение:** Post Type = `events_details`

| Имя поля | Метка | Тип | Обязательное |
|----------|------|-----|--------------|
| event_date | Дата события | Date Picker | Нет |
| description | Описание | WYSIWYG Editor | Нет |
| main_image | Главное фото | Image | Нет |
| gallery_image_1 | Фото галереи 1 | Image | Нет |
| gallery_image_2 | Фото галереи 2 | Image | Нет |
| gallery_image_3 | Фото галереи 3 | Image | Нет |

**Show in REST API** → Сохранить

---

## Группа 3: Команда

**Название группы:** Поля сотрудника

**Расположение:** Post Type = `team_members`

| Имя поля | Метка | Тип | Обязательное |
|----------|------|-----|--------------|
| position | Должность | Text | Да |
| short_description | Краткое описание | Textarea | Нет |
| description | Полное описание | WYSIWYG Editor | Нет |
| photo | Фото | Image | Нет |

**Show in REST API** → Сохранить

---

## Группа 4: Вакансии

**Название группы:** Поля вакансии

**Расположение:** Post Type = `vacancies`

| Имя поля | Метка | Тип | Обязательное |
|----------|------|-----|--------------|
| description | Описание | WYSIWYG Editor | Нет |
| requirements | Требования | Repeater (sub: text) | Нет |
| responsibilities | Обязанности | Repeater (sub: text) | Нет |

**Repeater:** внутри добавьте подполе `text` (тип Text) для каждого пункта.

**Show in REST API** → Сохранить

---

## Группа 5: Продукты (для винной карты и др.)

**Название группы:** Поля продукта

**Расположение:** Post Type = `products`

| Имя поля | Метка | Тип | Обязательное |
|----------|------|-----|--------------|
| product_image | Изображение | Image | Нет |
| short_description | Краткое описание | Textarea | Нет |
| price | Цена | Text | Нет |
| weight | Вес | Text | Нет |
| ingredients | Ингредиенты | Textarea | Нет |
| product_type | Тип | Select (special, dish, drink) | Нет |
| category | Категория | Text | Нет |

**Show in REST API** → Сохранить

---

## Группа 6: Преимущества (Benefits)

**Название группы:** Поля преимущества

**Расположение:** Post Type = `benefits`

| Имя поля | Метка | Тип | Обязательное |
|----------|------|-----|--------------|
| description | Описание | Textarea | Нет |
| icon | Иконка | Image | Нет |

**Show in REST API** → Сохранить

---

## Как добавить поле в ACF

1. **ACF** → **Группы полей** → **Добавить новую**
2. Введите **название группы** (например, «Поля меню»)
3. В блоке **«Расположение»** выберите:
   - **Post Type** → **равно** → нужный тип (main_menu, events_details и т.д.)
4. В блоке **«Поля»** нажимайте **«Добавить поле»** и заполняйте по таблицам выше
5. Внизу страницы включите **Show in REST API**
6. Нажмите **«Сохранить»**

| Группа | Для типа записей | Где на сайте |
|--------|------------------|---------------|
| Поля меню | main_menu, game_menu | Страницы «Основное меню», «Меню из дичи» |
| Поля события | events_details | Страница «События» |
| Поля сотрудника | team_members | Страница «Команда» |
| Поля вакансии | vacancies | Страница «Карьера» |
| Поля продукта | products | Винная карта, продукты |
| Поля преимущества | benefits | Блок преимуществ |
