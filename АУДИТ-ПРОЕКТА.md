## Рекомендации для заказчика

### 1. Интеграция форм

API-маршруты `/api/booking` и `/api/career` сейчас только логируют данные. Нужно подключить:

- **Бронирование:** отправка на email, в CRM, Telegram-бот и т.д.
- **Карьера:** то же самое

Файлы для правки: `app/api/booking/route.ts`, `app/api/career/route.ts`

### 2. Медиа-файлы

| Файл | Назначение | Статус |
|------|------------|--------|
| favicon.ico | Иконка вкладки | Рекомендуется добавить |
| og-image.jpg | Превью в соцсетях (1200×630) | Рекомендуется добавить |
| hero-изображение | Фон главной страницы | Сейчас foto_center.svg — можно заменить на фото |

### 3. next.config.ts — строгая сборка

Сейчас отключены проверки TypeScript и ESLint при сборке. Перед продакшеном лучше включить:

```ts
typescript: { ignoreBuildErrors: false },
eslint: { ignoreDuringBuilds: false },
```

И исправить все ошибки.

### 4. Ссылка «Доставка»

В `config.ts` указано `yandexEda: 'https://eda.yandex.ru'`. Заменить на реальную ссылку на доставку ресторана.

### 5. Контакты

Проверить в `app/lib/config.ts`:

- Адрес, телефон, email
- Координаты для карты
- Часы работы
- Instagram
