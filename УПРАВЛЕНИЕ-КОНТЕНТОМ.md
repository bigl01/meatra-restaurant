# Управление контентом и отладка

## Как управлять контентом

### 1. Контент из WordPress (меню, события, команда, вакансии)

**Где:** https://testdomen.store/wp-admin

| Раздел сайта | Где в WordPress | Тип записи |
|--------------|-----------------|------------|
| Основное меню | Записи → Main Menu | main_menu |
| Меню из дичи | Записи → Game Menu | game_menu |
| События | Записи → Events | events_details |
| Команда | Записи → Team Members | team_members |
| Карьера (вакансии) | Записи → Vacancies | vacancies |
| Винная карта | Записи → Products (type=drink) | products |

**Обновление:** Редактируете в WordPress → сохраняете. Сайт обновится в течение ~1 часа (ISR). Для мгновенного обновления: Vercel → Deployments → Redeploy.

## Как отлаживать

### 1. Локальный запуск

```bash
cd /Users/bigl/MEATRA
npm install
cp .env.local.example .env.local
# В .env.local укажите:
# NEXT_PUBLIC_WORDPRESS_API_URL=https://testdomen.store/wp-json/wp/v2
# NEXT_PUBLIC_WORDPRESS_ACF_URL=https://testdomen.store/wp-json/acf/v3
# NEXT_PUBLIC_SITE_URL=http://localhost:3000

npm run dev
```

Откройте http://localhost:3000 — изменения видны сразу.

---

### 2. Консоль браузера

F12 → вкладка Console — ошибки JavaScript, сетевые запросы.

---

### 3. Проверка изображений

- 404 — файл не найден, проверьте путь и наличие в `public/`
- Долго грузится — большой файл (SVG >5MB лучше заменить на JPG/WebP)

---

### 4. Текст выходит за границы

Добавлены классы `line-clamp-2`, `max-w-full`, `break-words` для текста на карточках. Если всё ещё вылезает — укоротите текст в коде или в WordPress.
