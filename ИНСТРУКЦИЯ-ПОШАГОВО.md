## 📤 Шаг 2: Загрузить CORS-файл в WordPress

**Зачем это нужно:** Чтобы сайт на Vercel мог получать данные (меню, события, команду) с вашего WordPress.

### Вариант А: Через cPanel (File Manager)

1. **Войдите в cPanel** вашего хостинга
   - Обычно: `https://ваш-хостинг.by:2083` или ссылка из письма от хостинга
   - Логин и пароль — те же, что для хостинга

2. **Откройте File Manager** (Файловый менеджер)
   - Найдите иконку "File Manager" или "Диспетчер файлов"
   - Нажмите на неё

3. **Перейдите в папку WordPress**
   - Слева откройте папку `public_html`
   - Если WordPress в подпапке (например, `public_html/wp`) — зайдите в неё

4. **Найдите папку `wp-content`**
   - Внутри должна быть папка `wp-content`
   - Откройте её

5. **Проверьте папку `mu-plugins`**
   - В `wp-content` найдите папку `mu-plugins`
   - Если её нет — создайте: кнопка **+ Folder** → введите `mu-plugins` → Create

6. **Загрузите файл**
   - Зайдите в папку `mu-plugins`
   - Нажмите **Upload** (Загрузить)
   - Выберите файл `wordpress-cors.php` из папки проекта:
     ```
     /Users/bigl/MEATRA/scripts/wordpress-cors.php
     ```
   - Дождитесь окончания загрузки

7. **Проверьте**
   - В `wp-content/mu-plugins/` должен появиться файл `cors.php`
   - Путь: `public_html/wp-content/mu-plugins/cors.php`

### Вариант Б: Через FTP (FileZilla и т.п.)

1. Подключитесь к хостингу (хост, логин, пароль из панели хостинга)
2. Перейдите: `public_html` → `wp-content` → `mu-plugins`
3. Создайте `mu-plugins`, если её нет
4. Перетащите `wordpress-cors.php` в эту папку

## 🚀 Шаг 3: Задеплоить проект на Vercel

### Если проект уже подключён к GitHub

1. Откройте терминал (в Cursor: Terminal → New Terminal)
2. Выполните:

```bash
cd /Users/bigl/MEATRA
git add -A
git status
```

3. Если есть изменения — сделайте коммит и push:

```bash
git commit -m "Настройка для testdomen.store"
git push origin main
```

4. Vercel автоматически начнёт новый деплой (обычно 1–2 минуты)

### Если проект ещё не на GitHub

1. Создайте репозиторий на https://github.com/new
2. В терминале:

```bash
cd /Users/bigl/MEATRA
git init
git add -A
git commit -m "Первый коммит"
git remote add origin https://github.com/ВАШ_ЛОГИН/meatra-restaurant.git
git branch -M main
git push -u origin main
```

3. Зайдите на https://vercel.com → Add New Project → Import Git Repository
4. Выберите репозиторий и нажмите Deploy

## 🔍 Шаг 4: Проверить, что всё работает

### 1. Проверка WordPress API

Откройте в браузере:

```
https://testdomen.store/wp-json/wp/v2/posts
```

- Должен открыться JSON (список постов)
- Если видите ошибку или пустую страницу — API не работает

### 2. Проверка сайта на Vercel

Откройте ваш сайт на Vercel (ссылку вида `ваш-проект.vercel.app`):

- Главная страница загружается
- Меню, события, команда — если в WordPress есть данные, они должны подтягиваться

### 3. Если меню/события пустые

Это нормально, если в WordPress ещё нет записей. Добавьте их в админке:

- `https://testdomen.store/wp-admin`
- Плагины: ACF, ACF to REST API, Custom Post Type UI (см. DEPLOYMENT.md)

## ❓ Частые проблемы

**"CORS error" в консоли браузера**
→ CORS-файл не загружен или загружен не в ту папку. Должно быть: `wp-content/mu-plugins/cors.php`

**Картинки не загружаются**
→ В `next.config.ts` должен быть домен `testdomen.store` (уже добавлен)

**Меню/события пустые**
→ Добавьте контент в WordPress и настройте Custom Post Types (см. DEPLOYMENT.md)
