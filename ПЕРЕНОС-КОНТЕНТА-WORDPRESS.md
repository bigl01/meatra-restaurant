# Перенос контента WordPress с локального на боевой сайт

## Что нужно перенести

| Что | Где настраивается | Как переносить |
|-----|-------------------|----------------|
| Custom Post Types (main_menu, events_details и т.д.) | CPT UI | Вручную или экспорт |
| Группы полей ACF | ACF | Экспорт/импорт или вручную |
| Записи (меню, события, команда, вакансии) | WordPress | Экспорт/импорт |
| Медиафайлы (фото) | Медиабиблиотека | Входят в полный экспорт |

---

## Способ 1: All-in-One WP Migration (рекомендуется)

### На локальном WordPress

1. Установите плагин **All-in-One WP Migration**
2. **All-in-One WP Migration → Export** → **Export to File**
3. Скачайте файл `.wpress` (может быть большим)

### На боевом WordPress (testdomen.store)

1. Установите **All-in-One WP Migration**
2. **All-in-One WP Migration → Import** → **Import from File**
3. Выберите скачанный файл
4. Дождитесь окончания импорта
5. Плагин предложит выйти — выйдите и зайдите снова

**Важно:** Перед импортом на боевом сайте должны быть установлены те же плагины: **ACF**, **CPT UI**. Иначе типы записей и поля не подтянутся.

---

## Способ 2: Стандартный экспорт/импорт WordPress

### На локальном

1. **Инструменты → Экспорт**
2. Выберите **«Всё содержимое»**
3. Скачайте XML-файл

### На боевом

1. **Инструменты → Импорт**
2. Установите **«WordPress»** (если ещё не установлен)
3. Запустите импорт, выберите XML-файл
4. Отметьте **«Загрузить и импортировать вложения»** (чтобы перенести картинки)
5. Назначьте автора записей (существующего пользователя)

**Ограничение:** Стандартный экспорт не всегда корректно переносит Custom Post Types и ACF. Лучше использовать Способ 1.

---

## Способ 3: Ручная настройка

Если локального WordPress нет или экспорт не подходит:

### 1. Типы записей (CPT UI)

На боевом сайте создайте типы так же, как в `DEPLOYMENT.md`:
- main_menu, game_menu, events_details, team_members, vacancies, benefits, products

### 2. Группы полей ACF

Создайте группы по инструкции в `ACF-ГРУППЫ-ПОЛЕЙ.md`.

### 3. Контент

Добавьте записи вручную в **Записи** → нужный тип (Main Menu, Events и т.д.).

---

## Чек-лист перед импортом на боевом

- [ ] Установлены плагины: ACF, CPT UI
- [ ] Включено **Show in REST API** в группах ACF
- [ ] Файл CORS загружен в `wp-content/mu-plugins/`
- [ ] Permalinks: **Настройки → Постоянные ссылки** → «Название записи» → Сохранить

---

## После переноса

1. Проверьте API: `https://testdomen.store/wp-json/wp/v2/main_menu`
2. Если данные есть — сайт подтянет их в течение ~1 часа
3. Для быстрого обновления: Vercel → Redeploy

---

## Если All-in-One ограничивает размер

Бесплатная версия ограничивает импорт (обычно 512 MB). Варианты:

- Уменьшите размер: удалите старые ревизии, сожмите изображения
- Или используйте **WP Migrate DB** / **Duplicator** (другие плагины)
- Или перенесите только контент через стандартный экспорт + вручную настройте CPT и ACF
